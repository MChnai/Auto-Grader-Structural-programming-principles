# P00.3 — JUnit 5 regression suite (AutoGrader-X)

## Mục đích và phạm vi

- Bảo vệ **hành vi đang hoạt động** của AutoGrader V2, không lặng lẽ sửa source production.
- Biến AC, WA, CE, RE, TLE thành kiểm thử tích hợp CLI chạy trong **JVM con có watchdog 20 giây** vì baseline `SubmissionGrader` chưa đóng thread pool.
- Thêm kiểm thử cho tám module: ZIP, compiler, native execution, C++ analyzer, grader, output comparison, Winnowing và Picocli.
- Tách các **lỗi P00.2 đã biết** ra `KnownDefectsTest` với `@Disabled`; chúng **không phải PASS**, phải kích hoạt sau khi fix ở P02/P04/P09/P10.
- Dữ liệu C++ được tạo từ fixture vô hại trong `@TempDir`, **KHÔNG chạy source sinh viên thật** bằng native executor.

## Điều chỉnh test V2 hiện có

- `ZipExtractorTest`: trường hợp ZIP rỗng/không có `.cpp` được **characterize** đúng theo hợp đồng hiện tại (extract thành công; compiler từ chối sau).
- `CompilerEngineTest`: không phụ thuộc LF/CRLF khi kiểm tra `30`; RE test dùng `return 7` thay vì phép chia cho 0 có UB.
- Không thay đổi `src/main/java/**` hoặc `pom.xml`; dependency JUnit 5.10.2 đã có trong POM.

## Chạy kiểm thử trên Windows PowerShell

```powershell
java -version
g++ --version
mvn -version
python scripts/check_repo_hygiene.py
mvn -B -ntp clean test
mvn -B -ntp clean verify
```

Lọc suite mới (đề xuất khi cần xác định lỗi):

```powershell
mvn -B -ntp '-Dtest=*RegressionTest' test
```

Chạy lại audit độc lập (không thay thế JUnit):

```powershell
mvn -B -ntp -DskipTests package
python scripts/p00_2/run_audit.py `
  --runtime-jar target/autograder-1.0.0-cli.jar `
  --output-dir p00-2-results-after-p003
```

Ghi log vào file cục bộ (không commit output build/log):

```powershell
mvn -B -ntp clean verify *>&1 | Tee-Object -FilePath p00-3-maven.log
```

## Quy tắc CI / Platform

- `g++` không khả dụng: compiler/native/grade tests dùng JUnit assumption và sẽ được **SKIPPED**, không phải PASS.
- Java 21 và Maven 3.9+ được khuyến nghị; dùng `pom.xml` V2.
- Không dùng fixed absolute path; newline được chuẩn hóa tại assertions.
- Native execution trong test chỉ chạy fixture do test tự tạo; người dùng không được chấm mã không tin cậy bằng CLI V2.
- Timeout/IO deadlock nguy hiểm được kiểm tra riêng bởi P00.2 subprocess watchdog; test chuẩn hậu sửa `@Disabled` cho đến khi P02 bảo đảm an toàn.
- CI P00.3 sử dụng `mvn clean verify`; quan sát pass/fail trên máy chạy vẫn phải lưu lại.

## Exit criteria

1. `mvn clean verify` chạy trên máy có Maven/JDK 21 + g++; ghi lại log và môi trường.
2. Không còn false-failing baseline tests từ giả định sai của P00.2.
3. Có JUnit regression active cho cả 8 module, bao gồm AC/WA/CE/RE/TLE.
4. Có danh mục đầy đủ 14 lỗi đã biết, không báo chúng là đã sửa.
5. Có thể tạo feature PR riêng. **Không merge local.**

> Mốc này là *test infrastructure & characterization*, không phải sửa lỗi hệ thống. P02/P04/P09/P10 xử lý các FAIL.
